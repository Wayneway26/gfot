# gfot macOS 预览版（0.2.0）

更新时间：2026-10-20。

## 当前产品

自己的 macOS GUI → 本地任务服务 → 内置 OpenCode Agent Loop → 用户配置的本机 OpenAI 兼容代理 → 上游模型。

同一个本地项目、同一个任务和 OpenCode 会话，可以在回合之间选择不同模型连接。模型改变，执行器保持不变。这与切换到 WorkBuddy / Codex 的完整 Agent 执行器不同。

## 可用范围

- 原生目录选择、持久化任务和对话、执行事件与工具批准。
- 本机代理连接管理，访问密钥由 macOS 钥匙串保护的主密钥加密。
- 修改文件、运行命令与访问项目外目录需批准。权限提示不是操作系统沙箱。
- 停止或退出时清理执行进程；本地服务异常消失时，监督进程清理执行进程组。重启时将未完成任务标为中断，用户应核对文件再继续。
- Apple silicon 的 unsigned ZIP 和 .app；尚未签名、公证，也未验证 Intel Mac。

## 尚未接入

不自动读取其他 Agent 的订阅凭证，不查询各家的剩余额度，不做自动故障切换。WorkBuddy 完整执行器、Codex 完整执行器和 Harness² 递归改进均不在本次桌面版中。不能把“代理可达”当成“某家订阅可用”。

## 验收证据

自动测试以本机合成模型驱动真实 OpenCode，验证批准后写入临时文件、工具结果回传、关闭服务再打开后保留会话并切换模型。原生 Electron 界面测试检查渲染隔离、目录选择桥接、连接编辑不改变选择，以及同一会话的两轮模型执行。真实供应方账号兼容性需另行验证。

## 与旧工作台的关系

原 gfot-prd.md 描述的是旧版“多 Agent 手工交接 / 独立审查”工作台，仍可通过 npm start 运行。它与桌面预览版的数据目录和任务不同，不会自动迁移。当前桌面产品范围以本文和 README.md 为准。
