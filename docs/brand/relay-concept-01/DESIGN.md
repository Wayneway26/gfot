# gfot · Relay mark · Concept 01

Approved and adopted, 2026-10-26. Canonical application source: desktop/ui/brand-mark.svg. The original presentation board retains its draft caption as design history.

A single-storey geometric g, split once at a diagonal handoff seam. The charcoal body preserves the letter; the cobalt terminal completes its descending stroke. The idea is a different Agent continuing the same task.

Colors: charcoal #242624; blue #2862F5.

- mark.svg / mark.png — standalone mark, transparent background.
- mark-mono.svg — single-color version.
- mark-reverse.svg — white version for dark backgrounds.
- app-icon-preview.svg / .png — desktop icon concept.
- presentation.svg / .png — design board with monochrome, app-icon and 16/24/32/48px comparisons.

SVG geometry is the source of truth. Presentation text is editable text; the mark itself has no font dependency or external assets.
