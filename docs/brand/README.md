# gfot visual identity

The 2026-10-21 identity implements the approved cobalt/cyan lowercase-g concept as a reproducible vector mark. The original generated presentation remains in gfot-logo-concept-v1.png.

- Canonical mark: ../../desktop/ui/brand-mark.svg
- Header: ../readme-hero.svg
- Application exports: ../../desktop/assets/icon.svg, icon.png, icon.icns
- Palette: cobalt #2862F5, cyan #22CBE5, navy #14213D, white.

Run `npm run brand:assets` on macOS to regenerate the README header and application icon exports from the canonical SVG. The script rasterizes the vector through Electron and packages icon sizes with macOS sips/iconutil. It does not edit the original generated concept image.
