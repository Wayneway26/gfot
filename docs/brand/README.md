# gfot visual identity

The current identity is the Relay mark, approved on 2026-10-26: a charcoal geometric g and a blue finishing stroke separated by a diagonal handoff seam.

- Canonical mark: ../../desktop/ui/brand-mark.svg
- Approved design: relay-concept-01/mark.svg
- Header: ../readme-hero.svg
- Application exports: ../../desktop/assets/icon.svg, icon.png, icon.icns
- Palette: charcoal #242624, blue #2862F5, off-white #F7F8F5.

Run `npm run brand:assets` on macOS to regenerate the README header and application exports from the canonical SVG. The script preserves the source viewBox and clip geometry, rasterizes with Electron and packages native sizes with sips/iconutil.

The earlier 2026-10-21 cobalt/cyan identity and gfot-logo-concept-v1.png are retained as historical design references. The original Relay presentation board also retains its draft-stage caption; the mark itself is now adopted.
