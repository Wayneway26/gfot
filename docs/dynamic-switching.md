# 同一任务，切换 Agent 继续

项目目录、任务对话和执行进度由 gfot 保存。切换执行器时，目标 Agent 使用自己的账号与模型配置，工作仍留在原项目和原任务中。

## 使用

1. 新建任务并选择目录。相同目录的任务归在左侧同一个项目下。
2. 在 **项目记忆** 中保存项目约定，在 **任务记忆** 中保存本任务要求。
3. 选择其他执行 Agent，或点击 **切换并继续**。确认接手方，并选择是否立即继续。
4. gfot 请求结束旧执行、保存交接记录，再启动目标 Agent。目标先核对已有文件和操作，继续尚未完成的工作。

遇到可识别的额度或速率限制时，任务会显示 **切换 Agent 继续**。这是用户确认的交接，不会自动轮询所有账号、充值、重置限额或重放失败请求。部分服务只返回通用错误，仍可从任务中主动切换。

使用 Codex 订阅额度时，选择内置 OpenCode 和导入的 Codex 账号连接；此路径使用 OpenCode 执行循环，不是控制 Codex 桌面应用。本机 OpenCode、WorkBuddy、WorkBuddy AI 使用其 CLI 的原生登录。豆包使用实验性桌面接口。WorkBuddy 仍需完成 CLI 登录；千问尚不可执行。具体支持范围见 [本机 Agent 接入](local-agents.md)。

## 共享内容

- 项目约定、任务备注、原始目标和近期用户要求。
- 近期可见对话，以及中断时已经收到的部分输出。
- 有界的工具输入、输出、错误与状态记录。
- Git 仓库根目录的当前文件状态；只观察文件名和状态，不自动读取补丁或文件内容。状态可能包含执行前已有的修改。
- 同一项目中至多三个其他任务的有限摘要，不包含其他项目。

右侧 **任务交接记录** 可查看保存的目标、结果、工具证据和文件状态。本轮准备发送的字符数、对话条数、工具证据数量及预算删减量也会显示。这里的记录不包含原生 Agent 的私有推理、隐藏提示词或缓存。

项目和任务备注各最多 8000 字符。普通回合的合并输入预算为 60000 字符，包含共享记录、当前请求、近期对话与已采用的执行指令；这不是精确的模型 Token 计数。较早对话或低优先级证据会被删减并显示数量；必要记忆与当前指令本身超限时，执行会明确失败，要求缩短内容。接手 Agent 应继续核对实际项目文件。

## 结束确认与恢复

交接期间，同一任务不能再次发送、切换或修改任务记忆；待续接的任务也占用执行名额。目标账号在本机已经退出、缺少凭证或已过期且无法刷新时，会在停止旧任务之前拒绝切换。

ACP 的原生回合回应用于确认结束，关闭连接或杀掉自有进程本身不算确认。未收到结束回应时，gfot 保留原任务并阻止交接。只有在原应用核对任务已经结束后，才能点击 **确认旧任务已结束**。原生后台服务和已批准工具仍按各 Agent 自己的权限策略工作；gfot 不是操作系统沙箱。

豆包继续使用精确轮次 ID 核对和停止；接收状态未知时不会重发。遇到尚未适配的原生交互确认，会请求停止并报告错误。

退出或崩溃后，不会自动重放切换或任务。再次打开时，对话、项目记忆、执行器会话和已保存的交接记录保留；进行中的原生执行会要求核对。Harness² 提示词优化是独立的可选功能，切换无需运行优化。
